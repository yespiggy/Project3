## Added job scripts

- smoke_cpu.pbs: serial and MPI tests on four small graphs, 1/2/4 ranks.
- smoke_gpu.pbs: serial, single-GPU kernels, and one/two-GPU MPI comparisons.
- prep_synthetic.pbs: generate the 1–144-core R-MAT input family.
- scale_synthetic.pbs: strong scaling on rmat_p144.bin and weak scaling on the
  matching rmat_p<cores>.bin. Set NN and matching PBS resources for two nodes.
- strong_720.pbs: ten nodes, 72 cores/node, 30 minutes, no queue directive.
  Uses rmat_p144.bin and 20 iterations, three measured repetitions, matching
  the smaller strong-scaling runs. This is NOT a 720-core weak-scaling test.

These added scripts retain the submitting account's P3_ROOT path so the submitted
jobs are reproducible. Teammates must change that assignment to their checkout
path before use; set P3_DATA to a readable shared graph directory if applicable.
Run qsub from the jobs/ directory. Use distinct output directories for reruns.
Python tests use .venv/bin/python with NumPy, SciPy and NetworkX installed.
